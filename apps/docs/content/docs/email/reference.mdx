## Client methods

| Method | Result |
| --- | --- |
| `validate(message)` | Resolves after local validation. |
| `send(message, options?)` | Returns one normalized send result. |
| `sendMany(messages)` | Returns ordered settled results. |
| `sendPersonalized(input)` | Returns accepted and rejected recipients. |
| `flush()` | Waits for pending telemetry and never rejects. |

## Result fields

`EmailSendResult` includes `adapter`, `accepted`, `rejected`, `id`, and raw provider data.

## Error classes

| Class | Meaning |
| --- | --- |
| `EmailValidationError` | The message or selected route failed before dispatch. |
| `EmailAdapterNotFoundError` | The requested adapter is not registered. |
| `EmailAdapterError` | One adapter failed and reports delivery status. |
| `EmailRouteError` | Every configured route failed. |
| `EmailAllRecipientsFailedError` | A personalized send accepted no recipients. |
