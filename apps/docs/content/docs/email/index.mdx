---
title: Email SDK
description: Send transactional email through typed provider adapters.
---

`@opencoredev/email-sdk` is an installable TypeScript library. Your server calls the provider adapter directly.

```ts
import { createEmailClient } from "@opencoredev/email-sdk";
import { resend } from "@opencoredev/email-sdk/resend";

const email = createEmailClient({
  adapters: [resend({ apiKey: process.env.RESEND_API_KEY! })],
});
```

The client normalizes messages, validation, retries, fallback, and provider errors. It does not host an email service.

## Choose Email SDK when

- You need one message contract across providers.
- You want provider changes to stay behind adapter imports.
- You need dry-run validation before a network request.

## Know the limit

Providers do not support the same fields. The SDK rejects unsupported fields instead of dropping them.
