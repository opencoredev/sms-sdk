---
title: Send email
description: Validate a message, send it through Resend, and inspect the receipt.
---

Create one client for the adapters your app uses.

```ts title="src/send-welcome.ts"
import { createEmailClient } from "@opencoredev/email-sdk";
import { resend } from "@opencoredev/email-sdk/resend";

const email = createEmailClient({
  adapters: [resend({ apiKey: process.env.RESEND_API_KEY! })],
});

const message = {
  from: "Product <hello@example.com>",
  to: "reader@example.com",
  subject: "Your account is ready",
  text: "Sign in to continue.",
};

await email.validate(message);
const result = await email.send(message);
console.log(result.adapter, result.id);
```

`validate` runs the message and route checks without a provider request. `send` returns the adapter name and provider receipt data.
