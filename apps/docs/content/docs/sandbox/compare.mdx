---

Use Sandbox SDK when provider portability and one capability contract matter.

| Choice | Best fit | Cost |
| --- | --- | --- |
| Sandbox SDK | Your app may use more than one provider. | You use the shared contract instead of every provider feature. |
| Provider SDK | One provider owns the full lifecycle. | A provider change needs application changes. |
| Local process | You trust the code and need no isolation. | The process shares the host boundary. |

The memory adapter is a test adapter. It is not an isolated local process.
