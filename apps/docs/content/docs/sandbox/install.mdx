---
title: Install
description: Add Sandbox SDK and choose the memory or cloud adapter.
---

Install the package with Bun.

```bash
bun add @opencoredev/sandbox-sdk
```

The memory adapter needs no provider account.

```ts
import { memory } from "@opencoredev/sandbox-sdk/memory";
```

Cloud adapters use package subpaths such as `/e2b`, `/daytona`, and `/vercel`. Install the provider peer package required by that adapter.

## Check available adapters

```bash
bunx sandbox-sdk adapters
```
