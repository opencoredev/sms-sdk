title: Email support
description: Diagnose a failed send without exposing content, addresses, or credentials.
---

Start with the exported error class. Provider text alone cannot prove whether dispatch happened.

## Run a dry check

```bash
EMAIL_SDK_TELEMETRY=0 bunx email-sdk send \
  --adapter resend \
  --from hello@example.com \
  --to reader@example.com \
  --subject "Validation check" \
  --text "Dry run only." \
  --dry-run
```

## Classify delivery

- `not_sent` allows fallback.
- `unknown` stops fallback by default because the provider may have accepted the message.
- `EmailRouteError.failures` keeps the ordered adapter failure chain.

## Check account state

`doctor` checks required values. It cannot verify sender domains, account review, rate limits, or provider sandbox rules.
