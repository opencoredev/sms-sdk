Record the adapter, sandbox ID, operation, capability state, and normalized error. Remove tokens and file contents.

## Check capabilities

Run the CLI before the provider call.

```bash
bunx sandbox-sdk capabilities --adapter memory
```

## Check command output

`sandbox.$` throws `CommandFailedError` for a nonzero exit. Use `sandbox.run()` when you need the full result without shell-template behavior.

## Check cleanup

Confirm whether your code called `stop` or `destroy`. Scoped disposal calls `stop`.

## Check the security boundary

Do not use the memory adapter for untrusted code. Use a provider that creates an isolated runtime.
