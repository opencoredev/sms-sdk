# SDK Field Guide

This repository is a local workspace for two OpenCore packages and one shared documentation app.

- **Email SDK** means `@opencoredev/email-sdk`.
- **Sandbox SDK** means `@opencoredev/sandbox-sdk`.
- **Field Guide** means the Fumadocs app in `apps/docs`.
- **Quest** means an optional documentation progress task. A quest never blocks access to reference material.
- **Release** means one of the four ordered product update chapters in the Field Guide.

The Field Guide opens on documentation. It has no marketing landing page.
